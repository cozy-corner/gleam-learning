# Hello World

ExercismのGleamトラックのHello Worldへようこそ。
テストの実行やコードの提出について助けが必要な場合は、`HELP.md`を確認してください。

## Instructions

古典的な入門用の演習です。
ただ"Hello, World!"と言うだけです。

["Hello, World!"][hello-world]は、新しいプログラミング言語や環境でプログラミングを始めるときの、伝統的な最初のプログラムです。

目標はシンプルです：

- 用意されたコードを変更して、文字列"Hello, World!"を出力するようにします。
- テストスイートを実行して、成功することを確認します。
- 解答を提出して、ウェブサイトで確認します。

すべてうまくいけば、最初の本格的な演習を取得する準備が整います。

[hello-world]: https://en.wikipedia.org/wiki/%22Hello,_world!%22_program
